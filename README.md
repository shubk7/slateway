# Slateway

Turn an Android tablet into a second screen, pen and touch input, microphone and camera for your Windows or Linux PC. Free, open source (GPLv3), USB-first, no ads, no tracking.

**Status:** pre-alpha, in design. See `docs/ROADMAP.md`.

**Why:** existing tools are closed, paid, missing Linux, short on features, wireless-only, or ad-supported. Goals and principles: `docs/SCOPE.md`.
